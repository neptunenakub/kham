ทำงานยังไง

01

ค้นจากตัวที่หายากที่สุด

คลังคำถูกทำ index ตามตัวอักษร เวลาค้นจะเริ่มจากตัวอักษรที่มีคำน้อยที่สุด แทนที่จะไล่ทั้ง 60,000 คำ เลยตอบได้ในไม่กี่มิลลิวินาที

02

เรียงตามที่คนนึกถึงก่อน

ให้คะแนนความคุ้นเคยจากความถี่ใน Thai National Corpus และ Thai Textbook Corpus ถ่วงน้ำหนักให้ภาษาชีวิตประจำวันมากกว่าภาษาข่าว คำประสมอย่าง "การบ้าน" ได้คะแนนจากส่วนประกอบด้วย

03

จัดตระกูลคำแบบคน

หาคำที่ซ่อนอยู่ในคำ (การ + เรียน) แล้วต่อเป็นสาย การ → การบ้าน การงาน จากนั้นเล่นคำต่อจากชิ้นที่เพิ่งเห็น การเรียน → เรียน → นักเรียน

ใช้ในโค้ดของคุณ

Python ล้วน ไม่มี dependency · ใช้ใน bot, เกม หรือ API ได้เลย

# pip install git+https://github.com/your-username/kham
from kham import WordFinder

wf = WordFinder()
wf.search(letters="กรน", limit=5)
# ['นักเรียน', 'นักร้อง', 'การบ้าน', 'การงาน', 'งานการ']

wf.search(starts="นัก", sort="long", limit=3)
# ['นักสังคมสงเคราะห์', 'นักประชาสัมพันธ์', 'นักประวัติศาสตร์']

wf.search(pattern="ก?ร")        # ? = 1 ตัว, * = กี่ตัวก็ได้
wf.families(wf.search(letters="รก", limit=50))
# หลัง pip install จะมีคำสั่ง kham (หรือใช้ python -m kham)
kham กรน                     # คำที่มี ก ร น
kham กรน --only              # คำที่ใช้แค่ ก ร น
kham --starts นัก --sort long
kham --pattern "ก?ร*" --max 5
kham รก --families --json
